# react-lab

Small, focused experiments on how React actually works: rendering, state snapshots, reconciliation and identity, effects and closures, performance, and React 19 features.

Each lab lives in `src/labs/<nn>-<topic>/` and starts with a prediction written before running the code, followed by what really happened and why.

## Run

```bash
npm install
npm run dev
```

Stack: React 19, TypeScript, Vite.
